What the work includes

01

Workflows and logic

We review the process, user roles, data and constraints, then define the first release and its acceptance criteria.

02

Interface and features

I develop the screens and application logic. Authentication, data storage and access permissions are included as agreed.

03

Integrations and handover

I connect the services listed in the specification, check key flows and prepare the project for deployment.

DELIVERABLES

What you receive

  • A working application within the agreed scope.
  • Source code and a list of dependencies.
  • Setup, launch and access handover instructions.

Where to start

Describe who will use the application and the problem it should solve. Integrations require service documentation and agreed access.

New modules, ongoing administration and development after handover are planned separately from the first release.

Pricing and working terms

Price and milestones follow a review of the brief. Work starts after the contract and specification are signed, 100% prepayment is received, and the necessary materials and access are provided.

I correct deviations from the agreed specification. New ideas and scope changes are agreed separately; design iterations and support are defined before work starts.
